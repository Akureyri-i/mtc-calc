# MTC Calculator 0.1.1

Fixes the calculator showing nothing in the game on Windows 10 and on Windows 11 before 24H2. Download `MTC-Calculator.exe` below and run it in place of 0.1.0 (quit the old one from its notification area icon first). 中文说明见下方。

## Fixed

- **Nothing showed in the game on Windows 10 and older Windows 11.** The calculator asked Windows
  for capture options these versions don't have, so the capture never started. It now uses each
  option only where Windows has it. What that means there:
  - On Windows 10, Windows draws a yellow border round the Roblox window while the calculator
    runs. It is Windows showing that the window is being captured, and it can't be turned off on
    Windows 10.
  - The calculator gets at most about 60 frames a second, so on a high refresh rate screen the
    marks can trail the full map a little while you drag it.
- If the capture still can't start, the calculator now tells you once instead of silently showing
  nothing.
- Map pictures and data are downloaded once per run. Before, a capture that failed to start
  started the downloads again every two seconds.
- The scope map (M while looking through the sight) is no longer taken for the full map, which
  opened the plan panel in the sight.
- The log records the Windows version, to help with problem reports.

## Checking the download

- SHA-256 of `MTC-Calculator.exe`: `97eeb5734ced1d65f92ca7b7c2bd85e59c5613896545522d6eda45028e956c11`
- [VirusTotal report](https://www.virustotal.com/gui/file/97eeb5734ced1d65f92ca7b7c2bd85e59c5613896545522d6eda45028e956c11): 1 of 70 engines flags it, by a machine-learning score (Trapmine, "moderate"); the other 69 find nothing.

## Known issues

- Target marks jitter a little while you drag the full map.
- On Zone 11 the full map is matched less reliably, and targets can flicker.
- The heightmap shows trees by their crowns, so dense woods can still count as ground.
- At 1920×1080 it uses about twice the CPU it does at 2560×1440 (around 0.3 of one core).
- Near the edge of a charge's range the suggested charge can switch back and forth.
- Standing on your own empty vehicle's map icon after getting out, the gun position may not
  update.

Not in this version: a manual mode without the map, salvos and corrections, and counting the
rounds left.

## 中文

修复在 Windows 10 和 24H2 之前的 Windows 11 上，游戏里什么都不显示的问题。下载下面的 `MTC-Calculator.exe` 替换 0.1.0（先在通知区图标上右键退出旧版）。

### 修复

- **Windows 10 和较早的 Windows 11 上游戏里什么都不显示。** 计算器向 Windows 要了这些版本没有的捕获选项，画面捕获一直起不来。现在每个选项只在 Windows 支持时才用。在这些系统上：
  - Windows 10 会在计算器运行时给 Roblox 窗口加一圈黄框。这是 Windows 在提示这个窗口正在被捕获，Windows 10 上关不掉。
  - 计算器每秒最多拿到约 60 帧，高刷新率屏幕上拖动大地图时，标注可能稍微跟不上。
- 画面捕获还是起不来时，会提示一次，不再什么都不显示。
- 地图图片和数据每次运行只下载一次。以前捕获起不来时，每 2 秒就重新开始一轮下载。
- 开镜后按 M 打开的开镜地图不会再被当成大地图（以前会在瞄准镜画面里弹出计划面板）。
- 日志里记下 Windows 版本，方便处理问题报告。

### 核对下载的文件

- `MTC-Calculator.exe` 的 SHA-256：`97eeb5734ced1d65f92ca7b7c2bd85e59c5613896545522d6eda45028e956c11`
- [VirusTotal 报告](https://www.virustotal.com/gui/file/97eeb5734ced1d65f92ca7b7c2bd85e59c5613896545522d6eda45028e956c11)：70 家引擎里 1 家（Trapmine）按机器学习打分标为“中度”，其余 69 家都没有报。

### 已知问题

- 拖动大地图时，目标标注会轻微抖动。
- Zone 11 的大地图对准没那么稳，目标可能时有时无。
- 高度图里的树只有树冠，密林有时仍会被当成地形。
- 1920×1080 下的 CPU 占用大约是 2560×1440 的两倍（约 0.3 个核心）。
- 在某档装药的射程边缘，推荐装药可能来回切换。
- 下车后站在自己的空车图标上时，炮位可能不更新。

这个版本还没有：不用地图的手动模式、齐射和校射、剩余弹数。
