# MTC Calculator 0.1.4

Download `MTC-Calculator.exe` below and run it in place of the old one (quit the old one from its notification area icon first). 中文说明见下方。

## New

- **Map pictures, heightmaps and terrain layers for every map now come inside the program**, so it works on the first start without downloading them (they were slow or failing to download for many players, often from mainland China). The program is about 190 MB because of this. On start it copies them into its map folder once, which takes under a second.

## Fixed

- **The gun wasn't recognised and the shell stayed "unknown" on some computers.** The calculator reads the game's text by comparing it with the game's own font, which it takes from the Roblox install. It looked for that font in one folder only; where Roblox was installed elsewhere it silently used a Windows font instead, and every gun name read wrong (the panel was then drawn in that Windows font too). It now takes the font from the running Roblox, or from any of the usual install folders, and otherwise uses a copy of the font that now comes with the program. The log says which one it used.
- **Removed the message telling you to remove font packs or turn off translation.** It also appeared when the calculator itself misread the gun name, so it blamed the wrong thing. The log still records it.
- The message about Roblox running as administrator is now only written to the log.

## Please check your game settings

The calculator reads the game as it looks out of the box:

- In the game's settings, set the GUNNER section to: Align action bar Center, Action bar color #F0B74A, Hide minimap when aiming OFF, Weapon selection layout Horizontal, Keep action bar expanded while loading ON.
- Turn off Roblox's automatic translation and keep the game in English.
- Don't use a font pack that replaces the game's fonts.

## Checking the download

## Known issues

- Target marks jitter a little while you drag the full map.
- On Zone 11 the full map is matched less reliably, and targets can flicker.
- The heightmap shows trees by their crowns, so dense woods can still count as ground.
- At 1920×1080 it uses about twice the CPU it does at 2560×1440 (around 0.3 of one core).
- Near the edge of a charge's range the suggested charge can switch back and forth.
- Standing on your own empty vehicle's map icon after getting out, the gun position may not
  update.

Not in this version: a manual mode without the map, salvos and corrections, and counting the
rounds left.

## 中文

下载下面的 `MTC-Calculator.exe` 替换旧版（先在通知区图标上右键退出旧版）。

### 新增

- **所有地图的地图图片、高度图和地形层现在都随程序带上**，第一次启动不用再下载（很多玩家，尤其在大陆，下载很慢或下不下来）。程序因此变成约 190 MB。启动时会把它们复制进地图文件夹一次，不到一秒。

### 修复

- **有些电脑上认不出炮，弹种一直是 unknown。** 计算器是拿游戏自己的字体去比对画面上的字，字体从 Roblox 的安装目录里取。原来只在一个文件夹里找，Roblox 装在别处时就悄悄换成 Windows 自带的字体，炮名全部读错（面板也变成了那种字体）。现在从正在运行的 Roblox 或常见的安装位置取字体，都找不到时用程序自带的一份，日志里写明用的是哪个。
- **去掉了让你删字体包、关翻译的提示。** 计算器自己读错炮名时也会弹，怪错了对象。日志里仍然记录。
- Roblox 以管理员身份运行的提示改成只写进日志。

### 请检查游戏设置

计算器是照着游戏原本的样子认画面的：

- 游戏设置的 GUNNER 一节这样设：Align action bar 选 Center，Action bar color 是 #F0B74A，Hide minimap when aiming 选 OFF，Weapon selection layout 选 Horizontal，Keep action bar expanded while loading 选 ON。
- 关掉 Roblox 的自动翻译，游戏界面保持英文。
- 不要装替换游戏字体的字体包。

### 核对下载的文件

- `MTC-Calculator.exe` 的 SHA-256：`d375d8e94b1d2ba6d56c5f5dd14f019463fc5f7ac4874ad54053162136d0681f`

### 已知问题

- 拖动大地图时，目标标注会轻微抖动。
- Zone 11 的大地图对准没那么稳，目标可能时有时无。
- 高度图里的树只有树冠，密林有时仍会被当成地形。
- 1920×1080 下的 CPU 占用大约是 2560×1440 的两倍（约 0.3 个核心）。
- 在某档装药的射程边缘，推荐装药可能来回切换。
- 下车后站在自己的空车图标上时，炮位可能不更新。
