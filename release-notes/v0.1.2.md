# MTC Calculator 0.1.2

Fixes for what players reported on the first day. Download `MTC-Calculator.exe` below and run it in place of the old one (quit the old one from its notification area icon first). 中文说明见下方。

## Fixed

- **Roblox running as administrator wasn't found**, so nothing showed. The calculator now finds it either way, and tells you once to run the calculator as administrator too.
- **Map pictures and heightmaps that wouldn't download** (often from mainland China) now come from two places at once, the original map service and a copy on the calculator's own server, whichever finishes first.
- **The full map wasn't recognised at 200 % and 225 % display scaling**, so the plan panel never showed.
- **The charge was read wrong on screens with Windows HDR on** (the picture comes out over-bright when captured).
- **The calculator closed when the Windows display scaling was changed** while it ran.
- If the game's text can't be read at all (a font pack, or Roblox's automatic translation), the calculator now tells you once.
- The log records whether HDR is on, to help with problem reports.

## Please check your game settings

The calculator reads the game as it looks out of the box:

- In the game's settings, set the GUNNER section to: Align action bar Center, Action bar color #F0B74A, Hide minimap when aiming OFF, Weapon selection layout Horizontal, Keep action bar expanded while loading ON.
- Turn off Roblox's automatic translation and keep the game in English.
- Don't use a font pack that replaces the game's fonts.

## Checking the download

- SHA-256 of `MTC-Calculator.exe`: `9363853d9b0ee9870c45594d3992fcb60b16c0a7502276e30cfa401fccd73511`

## Known issues

- Target marks jitter a little while you drag the full map.
- On Zone 11 the full map is matched less reliably, and targets can flicker.
- The heightmap shows trees by their crowns, so dense woods can still count as ground.
- At 1920×1080 it uses about twice the CPU it does at 2560×1440 (around 0.3 of one core).
- Near the edge of a charge's range the suggested charge can switch back and forth.
- Standing on your own empty vehicle's map icon after getting out, the gun position may not
  update.

Not in this version: a manual mode without the map, salvos and corrections, and counting the
rounds left.

### 修复

- **计算器运行时改 Windows 显示缩放会闪退。**
